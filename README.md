# Hello Express App

A tiny Node.js Express application with a single `/hello` route that returns JSON.

## Requirements

- [Node.js](https://nodejs.org/) installed

## Setup

Install dependencies:

npm install

## Run

Start the server:

npm start

By default, the app runs on:

http://localhost:3000

## Test the `/hello` endpoint

Open this URL in your browser:

http://localhost:3000/hello

Or use `curl`:

curl http://localhost:3000/hello

Expected response:

{"message":"Hello, world!"}
